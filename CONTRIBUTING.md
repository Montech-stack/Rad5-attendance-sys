# Contributing

Thanks for your interest in contributing to Rad5 Attendance System! Please follow these guidelines to help us maintain a healthy project.

1. Fork the repo and create a feature branch named `feature/short-description` or a bugfix branch `fix/short-description`.
2. Keep changes focused and small. Open a draft pull request early if you want feedback.
3. Write clear commit messages and include a short description in PR bodies.
4. Follow the existing code style (TypeScript, React hooks, Tailwind classes, Radix components). Run `pnpm lint` before opening a PR.
5. If your changes affect the database, include migration SQL in `scripts/` and document it in the PR.
6. For UI changes, include screenshots or short GIFs in the PR description.

If you're unsure where to start, open an issue describing what you want to do and we can coordinate.
